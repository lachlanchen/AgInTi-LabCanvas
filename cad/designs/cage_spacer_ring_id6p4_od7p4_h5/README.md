# Cage Spacer Ring ID 6.4 / OD 7.4 / H 5

This project contains removable spacer rings for separating optical cage
elements along a rod.

`runs/run-1-id6p4-od7p4-h5-4x4-20260714T074753Z/`

- Inner diameter: `6.40 mm`
- Outer diameter: `7.40 mm`
- Height: `5.00 mm`
- Direct-print layout: `4 x 4`, flat on the annular face
- Parts in the grid: `16` independent rings

The explicit `6.4 / 7.4 mm` diameters produce a `0.50 mm` radial wall. A true
`1.00 mm` radial wall around a `6.40 mm` bore would require an `8.40 mm` outer
diameter. This project follows the requested `7.40 mm` outer diameter.
