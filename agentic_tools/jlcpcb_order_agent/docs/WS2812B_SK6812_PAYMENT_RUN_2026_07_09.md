# WS2812B and SK6812 JLC Payment Run

Date: 2026-07-09

## Outcome

- `Y6`: `ws2812b-5050-rgb-led-jlcpcb-gerber`, submitted 2026-07-09 15:43:34, approved and pay-ready, `¥30.00`.
- `Y7`: `sk6812rgbw-5050-rgbw-led-jlcpcb-gerber`, submitted 2026-07-09 15:48:29, approved and pay-ready, `¥30.00`.
- `Y8`: duplicate retry of `sk6812rgbw-5050-rgbw-led-jlcpcb-gerber`, submitted 2026-07-09 17:36:37, `¥31.58`; do not include in the intended two-board payment.

The cashier page was opened once for `Y6 + Y7` only:

```text
payment_url=https://trade.jlc.com/pay/unifyPayInit/?payUuid=82ec6517517847e58149f9e72b4bab59
total=¥60.00
```

After the payment warning modal was acknowledged, JLC no longer kept the cashier
URL alive. A fresh order-list reload showed no pay-ready rows and listed:

- `Y6` as `已提交厂方`.
- `Y8` as `已提交厂方`.
- `Y7` was no longer visible in the current all-order list.

Do not cancel or modify these factory-submitted rows without human approval,
because JLC warns that cancellation after this step may charge a `10元工程费`.

## What Happened

The uploaded-file list still showed an `立即下单` action for SK6812 even though
an earlier submitted SK6812 order was already approved and waiting for payment.
Running the normal submit path again created duplicate `Y8`.

The order page also showed a `请选择板材类别` modal before the usual controls were
fully detected. The old helper selected `FR-4` too late, so it refused the page
as half-loaded.

## Fixes Added

- `jlc_order_cdp.py fill-settings` now clears the `请选择板材类别` modal before and during the form-control wait loop.
- `jlc_order_cdp.py open-payment` selects approved unpaid rows by Gerber stem, caps duplicates with `--max-per-stem 1`, verifies `--expected-total`, and only opens the cashier with `--allow-pay-page`.
- `jlc_order_cdp.py open-payment` now also handles the visible `我已知晓，继续支付` warning button and reports when JLC clears the pay-ready rows into a factory-submitted state.

## Operator Rule

Before reusing an uploaded Gerber row, check the `PCB未付款订单` summary first.
If the same Gerber stem is already approved and pay-ready, use `open-payment`
instead of clicking `立即下单` again.
